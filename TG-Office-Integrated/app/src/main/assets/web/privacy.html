Kebijakan Privasi

Berlaku sejak 18 Oktober 2026 · Versi 2.2 (TeGe Office 1.0.2)

TeGe Office adalah penampil dokumen DOCX, XLSX, PPTX, dan PDF untuk Android. Prinsipnya sederhana: dokumen Anda tetap di perangkat Anda.

Data yang diproses

  • Dokumen. File yang Anda buka dibaca dan ditampilkan langsung di perangkat. TeGe Office tidak mengunggah dokumen ke server luar.
  • Presentasi ke Layar Lain. Saat fitur ini dipakai, HP menjalankan server kecil di jaringan lokal agar browser layar tujuan (IFP, laptop, atau TV) bisa menampilkan presentasi. File PPTX hanya dikirim ke layar tujuan yang memasukkan kode 4 angka, tidak melewati internet, dan sesi berakhir saat Anda menekan Akhiri.
  • Riwayat dan sematan. Untuk fitur Terakhir dibuka dan Disematkan, aplikasi menyimpan alamat file (bukan salinannya), nama file, ukuran, waktu dibuka, dan posisi baca terakhir di penyimpanan internal aplikasi. Salinan file hanya disimpan untuk file yang aksesnya sementara (misalnya dari WhatsApp), maksimal 35 MB per file dan 60 MB total.
  • Pengaturan. Pilihan tema dan tampilan disimpan di perangkat.
  • Log diagnostik. Aplikasi mencatat kejadian teknis ringan (misalnya jenis dan ukuran file, lama memuat, pesan galat) di perangkat, tanpa nama file dan tanpa isi dokumen. Log tidak dikirim otomatis; log hanya keluar dari perangkat bila Anda sendiri menyalin atau membagikannya.

Yang tidak kami lakukan

  • Tidak ada akun, login, iklan, atau pelacak.
  • Tidak ada analitik dan tidak ada pengiriman data penggunaan.
  • Tidak ada penjualan atau pembagian data kepada pihak lain.

Fitur yang melibatkan aplikasi lain

  • Bagikan memakai lembar berbagi Android. Setelah Anda memilih aplikasi tujuan, file ditangani oleh aplikasi tersebut.
  • Cetak memakai layanan cetak Android. Printer atau layanan cetak yang Anda pilih (termasuk Simpan sebagai PDF) memproses dokumen sesuai kebijakannya masing-masing.
  • Kirim masukan membuka aplikasi surel Anda dengan alamat pengembang terisi. Tidak ada yang terkirim sampai Anda sendiri menekan Kirim di aplikasi surel.
  • Tautan ke totogutomo.com dibuka di peramban Anda.

Menghapus data

Ketuk Bersihkan di beranda untuk menghapus riwayat. Melepas sematan atau menghapus data aplikasi di Pengaturan Android menghapus semua salinan yang tersimpan.

Anak-anak

Aplikasi ini dibuat untuk guru dan pelajar. Aplikasi tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.
